# Keyboard shortcuts

These are the default shortcuts. **Ctrl** means **Cmd** on macOS. To change
a shortcut, go to **Settings → Shortcuts** (see
[Settings and themes](../guide/settings.md#shortcuts)).

Edit shortcuts that act on clips only work while the timeline is shown, and
no shortcut works while you're typing in a text field.

## File

| Action            | Shortcut         |
| ----------------- | ---------------- |
| New project       | Ctrl+N           |
| Open project…     | Ctrl+O           |
| Save project      | Ctrl+S           |
| Save project as…  | Ctrl+Shift+S     |

## Transport

| Action                          | Shortcut      |
| ------------------------------- | ------------- |
| Play / stop                     | Space         |
| Loop the selection / toggle loop | Ctrl+L       |
| Metronome                       | Ctrl+M        |
| Follow playhead                 | Ctrl+Shift+F  |

## Edit

| Action                                    | Shortcut                 |
| ----------------------------------------- | ------------------------ |
| Undo                                      | Ctrl+Z                   |
| Redo                                      | Ctrl+Y, Ctrl+Shift+Z     |
| Select all clips                          | Ctrl+A                   |
| Copy                                      | Ctrl+C                   |
| Cut                                       | Ctrl+X                   |
| Paste                                     | Ctrl+V                   |
| Duplicate clips (or the selected track)   | Ctrl+D                   |
| Delete clips (or the selected track)      | Delete, Backspace        |
| Split clips at the edit cursor            | Ctrl+K                   |
| Add an audio track                        | Ctrl+T                   |
| Group the selected tracks                 | Ctrl+G                   |
| Nudge the selection or cursor left        | ←                        |
| Nudge the selection or cursor right       | →                        |
| Move the selection to the track above     | ↑                        |
| Move the selection to the track below     | ↓                        |

When the browser has focus, **↑** and **↓** move through the file list
instead, and **Enter** opens the selected item.

## View

| Action                             | Shortcut        |
| ---------------------------------- | --------------- |
| Show / hide the browser            | Ctrl+B          |
| Show / hide the effects panel      | Ctrl+J          |
| Switch timeline / audio graph      | Ctrl+Shift+G    |
| Open / close the settings          | Ctrl+,          |
| Zoom the interface in              | Ctrl++, Ctrl+=  |
| Zoom the interface out             | Ctrl+-          |
| Reset the interface zoom           | Ctrl+0          |

## Mouse

| Gesture                                   | Effect                                   |
| ----------------------------------------- | ---------------------------------------- |
| Ctrl+mouse wheel or pinch on the timeline | Zoom the timeline                        |
| Mouse wheel on the ruler                  | Zoom the timeline                        |
| Click or drag the ruler                   | Move the playhead                        |
| Click an empty part of the timeline       | Place the edit cursor                    |
| Drag on an empty part of the timeline     | Draw a selection zone                    |
| Shift+click a clip                        | Add the clip to the selection or remove it |
| Ctrl+drag a clip                          | Drag a copy                              |
| Alt while dragging                        | Turn snapping off                        |
| Ctrl+click a track header                 | Add the track to the selection or remove it |
| Shift+click a track header                | Select a range of tracks                 |
| Shift+click **S**                         | Solo the track along with the tracks already soloed |
| Double-click a track header               | Show / hide the effects panel            |
| Double-click a volume bar                 | Reset the volume to 0 dB                 |

# Your first project

This walkthrough takes you from an empty project to a saved, looping
arrangement. You need a few audio files (WAV, MP3 or OGG), for example a
drum loop and a bass line.

## 1. Add your sample folder

1. Click the **folder +** button at the top of the browser, on the left of
   the window. If the browser is hidden, press **Ctrl+B**.
2. Pick the folder that holds your samples.

The folder now has a button above the file list. Click a file to hear it.
A preview with its waveform, length and format appears at the bottom of the
browser.

## 2. Set the tempo

The **BPM** field in the transport bar at the top sets the project's tempo.
Double-click it and type a value, for example `120`, or use its small
arrows to change it one step at a time.

## 3. Put audio on the timeline

Drag a file from the browser onto the timeline:

- Drop it **on a track** to add it there.
- Drop it **below the last track** to create a new track for it.

The clip snaps to the grid where you drop it. Add a second file the same way.

## 4. Play it

Press **Space** to play and **Space** again to stop. When you stop, the
playhead goes back to the **edit cursor**. To move the edit cursor, click an
empty part of the timeline or click the ruler.

## 5. Loop a section

Drag in the thin lane at the top of the ruler to draw a loop region. Looping
turns on, and playback repeats that section. Press **Ctrl+L** to switch
looping on and off.

## 6. Mix

On each track header, on the left of the timeline:

- Drag the **volume bar** sideways to change the level. Double-click it to
  reset it to 0 dB.
- Click **M** to mute the track or **S** to solo it.

## 7. Save

Press **Ctrl+S** and choose where to save the project. Projects are saved as
`.tonique` files. They store the arrangement and the location of each audio
file, not the audio itself.

That's it. Next, read [Editing clips](../guide/clips.md) to learn about
trimming, splitting and copying clips.
